# CodePitch AI 🚀
> Universal Architecture Engine, Pitch Deck & Technical Proposal Generator  
> Hosted 100% Client-Side on GitHub Pages: [fuadfadam.github.io/codepitch-ai](https://fuadfadam.github.io/codepitch-ai/)

---

## ۱. هویت و کارکرد سیستم
سامانه **CodePitch AI** یک میکروسس استاتیک و کلاینت‌محور (Zero-Backend) است. این نرم‌افزار شرح پروژه‌ها، ایده‌های استارتاپی یا نیازمندی‌های نرم‌افزاری را دریافت می‌کند و خروجی‌های زیر را به صورت همزمان ایجاد می‌کند:
1. **پروپوزال رسمی و مهندسی:** تحلیل نیازمندی‌ها، ریسک‌ها، فازبندی اجرا و جدول برآورد هزینه.
2. **دیاگرام تعاملی معماری (Mermaid.js):** رسم خودکار فلوچارت جریان داده و ارتباطات فنی.
3. **خروجی چاپی اداری (A4 PDF):** تبدیل سند به فرمت بدون به‌هم‌ریختگی زبان فارسی از طریق ماژول اختصاصی پرینت مرورگر.

---

## ۲. ویژگی‌های کلیدی
*   **پشتیبانی دو زبانه (FA / EN):** سوئیچ آنی رابط کاربری و هماهنگی کامل متن سند خروجی.
*   **تم‌های مستقل:** امکان تنظیم تم تاریک/روشن برای برنامه و انتخاب مجزای کاغذ سفید یا تیره برای چاپ.
*   **پشتیبانی از هر نوع مدل هوش مصنوعی:** فیلد باز ورود مدل (مانند `gemini-3.8-flash`، `gemini-4-hydrogen` و مدل‌های Groq).
*   **واترمارک شبکه‌ای:** درج واترمارک محافظتی با آدرس سایت و امکان حذف آن با فعال‌سازی نسخه Pro.
